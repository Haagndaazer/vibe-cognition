Project instructions for vibe-cognition. Covers MCP setup, the plugin release procedure (three manifests, CHANGELOG, whats-new.json, gates, Loki pin, human gates), the Anthropic plugin directory stable channel added in v0.49.0 (generated release branch built with tools/build_release_branch.py from the code commit after about a week on coltondyck, pushed with git push origin release, every version held for manual review, limits enforced by tests/test_release_branch.py), and the hard rule to run the tool-surface audit before every release that changes a tool.
